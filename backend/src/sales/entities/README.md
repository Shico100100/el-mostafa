# 🗄️ نماذج البيانات (Database Entities)

هذا المجلد يحتوي على تعريف "الجداول" في قاعدة البيانات لهذا القسم.

### 📜 ملفات الكود (Code Files)
كل ملف ينتهي بـ `.entity.ts` يمثل جدولاً حقيقياً في قاعدة البيانات.

1. **`*.entity.ts`**
   - **ما هو؟** رسم توضيحي للجدول.
   - **لماذا؟** ليخبر النظام ما هي الأعمدة (Columns) الموجودة (مثل الاسم، التاريخ، الكمية) ونوع كل منها.
   - **كيف يعمل؟** يقوم "محرك البيانات" (TypeORM) بقراءة هذه الملفات وإنشاء الجداول تلقائياً في PostgreSQL.
