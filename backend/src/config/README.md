# الإعدادات (Config)

هذا المجلد يحتوي على إعدادات النظام (مثل الاتصال بقاعدة البيانات، ومفاتيح الأمان).

### 📜 ملفات الكود (Code Files)
- **app.config.ts**: يحتوي على الإعدادات العامة للتطبيق مثل المنفذ (Port) والبيئة (Environment).
- **config.type.ts** و **app-config.type.ts**: ملفات لتعريف هيكل البيانات الخاص بالإعدادات لضمان عدم وجود أخطاء برمجية.

### 🛠️ الوظائف المتاحة (Key Functions)
- **تحميل الإعدادات**: قراءة البيانات من ملف الـ `.env`.
- **التحقق من الإعدادات**: التأكد من أن جميع المفاتيح المطلوبة موجودة وصحيحة.
- **إدارة الاتصالات**: ضبط كيفية اتصال النظام بقاعدة البيانات والخدمات الخارجية.
