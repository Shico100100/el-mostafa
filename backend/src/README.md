# 🛠️ كود النظام البرمجي (Backend Source Code)

هذا المجلد يحتوي على "العقل المدبر" للنظام، حيث يتم معالجة جميع البيانات والعمليات.

### 📜 الملفات الأساسية (Core Files)

1. **`main.ts`**
   - **ما هو؟** نقطة البداية للسيرفر.
   - **لماذا؟** لتشغيل النظام وإخباره بأي منفذ (Port) يجب أن يعمل عليه (3001).
   - **كيف يعمل؟** يفتح "باباً" للسيرفر ليستقبل طلبات المستخدمين من الواجهة الأمامية.

2. **`app.module.ts`**
   - **ما هو؟** الملف الجامع لكل أجزاء النظام.
   - **لماذا؟** ليربط جميع الأقسام ببعضها (المخازن، المبيعات، الحسابات).
   - **كيف يعمل؟** يقوم بـ "استيراد" كل الموديولات (Modules) وتجهيزها للعمل معاً.

---

### 📂 الأقسام (System Modules)

ينقسم النظام إلى عدة "موديولات" أو أقسام، كل قسم مسؤول عن وظيفة محددة:

- **`accounting/`**: إدارة الحسابات والقيود المالية.
- **`inventory/`**: إدارة المخازن والأصناف.
- **`sales/`**: إدارة عمليات البيع والعملاء.
- **`purchases/`**: إدارة المشتريات والموردين.
- **`manufacturing/`**: إدارة التصنيع والماكينات والإنتاج اليومي.
- **`users/`**: إدارة المستخدمين وصلاحياتهم.
- **`auth/`**: نظام تسجيل الدخول والأمان.
- **`notifications/`**: نظام التنبيهات (مثل تنبيهات نقص المخزون).
- **`reports/`**: استخراج التقارير والبيانات.
- **`dashboard/`**: الصفحة الرئيسية التي تعرض ملخصاً للبيانات.
- **`payroll/`**: نظام المرتبات وشؤون الموظفين.
- **`audit/`**: سجل المراقبة (من فعل ماذا ومتى؟).
