# الأدوات المساعدة (Utils)

هذا المجلد يحتوي على أدوات مساعدة (مثل تنسيق التاريخ، وعمليات الحساب).

### 📜 ملفات الكود (Code Files)
- **serializer.interceptor.ts**: يقوم بتنظيم وتصفية البيانات قبل إرسالها للمتصفح.
- **infinity-pagination.ts**: مسؤول عن تقسيم البيانات إلى صفحات (Pagination) لتسريع عرض القوائم.
- **validate-config.ts**: أداة للتأكد من أن جميع إعدادات النظام مدخلة بشكل صحيح.

### 🛠️ الوظائف المتاحة (Key Functions)
- **تنسيق البيانات**: تحويل البيانات من شكل إلى آخر لتسهيل استخدامها.
- **تحسين الأداء**: أدوات تساعد في تقليل حجم البيانات المرسلة وتسريع الاستجابة.
- **التحقق (Validation)**: وظائف للتأكد من صحة البيانات والمدخلات.
