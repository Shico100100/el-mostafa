# قاعدة البيانات (Database)

هذا المجلد يحتوي على إعدادات قاعدة البيانات الأولية وبذر البيانات (البيانات الأساسية مثل المستخدم المسؤول).

### 📜 ملفات الكود (Code Files)
- **data-source.ts**: الملف الرئيسي لضبط اتصال قاعدة البيانات (TypeORM).
- **seeds/**: مجلد يحتوي على البيانات التي تزرع في قاعدة البيانات عند البداية (مثل الأدوار والمستخدم الافتراضي).
- **migrations/**: يحتوي على ملفات تتبع التغييرات التي تطرأ على جداول قاعدة البيانات.

### 🛠️ الوظائف المتاحة (Key Functions)
- **تهيئة قاعدة البيانات**: إعداد الجداول والعلاقات بينها.
- **بذر البيانات (Seeding)**: إدخال البيانات التجريبية أو الأساسية للنظام.
- **إدارة الهجرة (Migrations)**: تحديث هيكل قاعدة البيانات بأمان دون فقدان البيانات.
