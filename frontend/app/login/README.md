# 🔑 تسجيل الدخول (Login Page)

هذا القسم هو بوابة الدخول الرسمية والآمنة للنظام.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي لصفحة تسجيل الدخول.
   - **لماذا؟** للسماح للمستخدمين بالولوج للنظام باستخدام بياناتهم الموثقة.
   - **كيف يعمل؟** 
     - يتلقى اسم المستخدم وكلمة المرور.
     - يرسل البيانات للسيرفر للتحقق من صحتها.
     - يحفظ "رمز الجلسة" (Token) في متصفح المستخدم لتمكينه من تصفح الأقسام الأخرى.

### 🛠️ الوظائف المتاحة (Key Functions)

- **المصادقة (Authentication)**: التأكد من هوية المستخدم قبل منح صلاحيات الدخول.
- **تأمين البيانات**: التعامل مع كلمات المرور بشكل مشفر وآمن.
- **إدارة الجلسات**: تسجيل خروج المستخدم تلقائياً عند الحاجة لضمان أمن المعلومات.
- **الحماية من الاختراق**: التصدي لمحاولات الدخول العشوائية المتكررة.
