# 👥 الموارد البشرية (Human Resources)

هذا القسم هو المسؤول عن إدارة شؤون الموظفين والرواتب في النظام.

### 📜 ملفات الكود (Code Files)

1. **`payroll/` (مجلد)**
   - **ما هو؟** المكون الخاص بإدارة كشوف الرواتب.
   - **لماذا؟** لحساب وصرف رواتب الموظفين الشهرية مع مراعاة الحوافز والخصومات.
   - **كيف يعمل؟** 
     - يتضمن ملف `page.tsx` داخل مجلد `payroll` للتعامل مع العمليات الحسابية المرتبطة بالرواتب.
     - يعرض كشوف الرواتب لمراجعتها قبل الاعتماد.

### 🛠️ الوظائف المتاحة (Key Functions)

- **إدارة الرواتب**: احتساب المستحقات الصافية لكل موظف.
- **كشوف الرواتب**: إنشاء كشوف رواتب مفصلة للموظفين.
- **تتبع الاستحقاقات**: مراقبة الأجور الأساسية والإضافية.
- **إدارة البيانات**: الاحتفاظ بسجل مالي لكل موظف في المؤسسة.
