# 📊 لوحة القيادة (Dashboard)

هذا القسم هو القلب النابض للنظام، حيث يوفر نظرة شاملة وفورية على أداء المصنع وكافة العمليات الحيوية.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي للوحة القيادة.
   - **لماذا؟** لعرض الإحصائيات، الرسوم البيانية، والتنبيهات الهامة في مكان واحد.
   - **كيف يعمل؟** 
     - يجمع البيانات من عدة مصادر (المبيعات، المشتريات، المخازن، الإنتاج).
     - يعرض مؤشرات الأداء الرئيسية (KPIs) باستخدام رسوم بيانية تفاعلية (Area, Bar, Pie charts).
     - يتضمن تنبيهات للنواقص في المخزون أو تأخيرات الصيانة.

2. **`control-tower/` (مجلد)**
   - **ما هو؟** مركز التحكم المتقدم (برج المراقبة).
   - **لماذا؟** لمراقبة العمليات اللحظية وإدارة المهام المعقدة بدقة عالية.

### 🛠️ الوظائف المتاحة (Key Functions)

- **ملخص العمليات**: عرض إجمالي المبيعات، المشتريات، ورصيد الخزينة الحالي.
- **تتبع الإنتاج**: مراقبة كميات الإنتاج وتوجهاته عبر الزمن.
- **تنبيهات المخزون والصيانة**: إشعارات فورية عند وصول صنف للحد الأدنى أو اقتراب موعد صيانة ماكينة.
- **تقارير قيمة المخزون**: تحليل مالي لقيمة البضاعة الموجودة في المستودعات.
- **تحليل الاتجاهات (Trends)**: مقارنة أداء الفترة الحالية بالفترات السابقة لاتخاذ قرارات مدروسة.
