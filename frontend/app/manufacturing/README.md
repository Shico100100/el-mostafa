# ⚙️ التصنيع (Manufacturing)

هذا القسم هو المسؤول عن إدارة عمليات التصنيع والإنتاج في المصنع.

### 📜 الصفحات (Pages)

#### 1. لوحة التحكم (`page.tsx`)
- عرض إحصائيات الماكينات (عدد الماكينات النشطة).
- روابط سريعة لكل قسم فرعي.

#### 2. الماكينات (`machines/`)
- إدارة الماكينات (إضافة، تعديل، حذف).
- عرض بطاقات الماكينات مع حالة الصيانة (متأخرة / مستحقة قريباً).
- ترقيم صفحات + بحث وتصفية.
- تقارير Excel (تصدير/استيراد).
- سجل الإنتاج لكل ماكينة.
- سجل الصيانة لكل ماكينة مع إضافة صيانة جديدة.

#### 3. الصيانة (`maintenance/`)
- عرض جميع سجلات الصيانة في جميع الماكينات.
- تصفية حسب الماكينة، النوع، الحالة.

#### 4. قوائم المواد BOM (`bom/`)
- إدارة قوائم المواد (BOM) لكل منتج (إنشاء، تعديل، عرض).
- إضافة بنود لكل BOM (منتج + كمية).
- تفجير BOM (Explode): تحليل متكرر لجميع المكونات المطلوبة.
- حساب التكلفة الإنتاجية.
- تصدير PDF تقرير للمورد.

#### 5. MRP (`mrp/`)
- تخطيط الاحتياجات بناءً على جداول الإنتاج المعلقة.
- تحليل المخزون الحالي + الوارد (أوامر شراء) مقابل الاحتياجات.
- تحديد المواد التي تعاني من عجز (SHORTAGE).

#### 6. الإنتاج والجدولة
- الإنتاج اليومي (`daily-production/`).
- جدولة الإنتاج (`schedule/`).
- التخطيط (`planning/`).

#### 7. الخامات (`raw-materials/`)
- إدارة الخامات مع حركات المخزون.
- سجل الاستهلاك.
- إعادة حساب المخزون.

#### 8. مراقبة الجودة (`qc/`)
- لوحة QC مع نسبة التلف.
- الفحوصات المعلقة والأخيرة.

#### 9. التشغيل والموارد
- الكشك (`kiosk/`): تسجيل الإنتاج السريع.
- المواعيف والحضور (`attendance/`).
- التكاليف الثابتة (`fixed-costs/`).
- القوالب (`molds/`).

### 🛠️ الوظائف الأساسية
- إدارة دورة التصنيع الكاملة من المواد الخام إلى المنتج النهائي.
- ربط BOM بعمليات الإنتاج اليومية لخصم المكونات تلقائياً.
- تخطيط الاحتياجات (MRP) بناءً على جداول الإنتاج.
- متابعة صيانة الماكينات والتنبيه عند التأخير.
- استيراد/تصدير بيانات الماكينات عبر Excel.
