# 🔧 قسم التجميع (Assembly Department)

هذا القسم هو المسؤول عن إدارة كافة عمليات التجميع، بدءاً من المكونات البلاستيكية والإكسسوارات وصولاً إلى المنتج النهائي وتغليفه.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** لوحة التحكم الرئيسية لقسم التجميع.
   - **لماذا؟** لتوجيه المستخدم إلى الأقسام الفرعية المختلفة (بلاستيك، إكسسوارات، تغليف، إلخ).
   - **كيف يعمل؟** يعرض بطاقات تفاعلية (Menu Cards) لكل قسم فرعي لسهولة الوصول.

2. **المجلدات الفرعية (`Subfolders`)**
   - **`accessories/`**: إدارة الإكسسوارات المستخدمة في التجميع.
   - **`plastic/`**: إدارة المكونات البلاستيكية.
   - **`packaging/`**: إدارة العلب والكراتين ومواد التغليف.
   - **`production/`**: تسجيل عمليات الإنتاج الفعلية في قسم التجميع.
   - **`attendance/`**: متابعة حضور وغياب العاملين في القسم.
   - **`bom/`**: إدارة قوائم المواد (Bill of Materials) الخاصة بالتجميع.

### 🛠️ الوظائف المتاحة (Key Functions)

- **متابعة المكونات**: مراقبة توافر المواد الخام (بلاستيك، إكسسوارات) اللازمة لبدء التجميع.
- **تسجيل الإنتاج**: توثيق الكميات المجمعة يومياً وربطها بأوامر الشغل.
- **إدارة التغليف**: تنظيم مخزون مواد التغليف والكراتين الصادرة.
- **إدارة العمالة**: كشف يومي للحضور والغياب لضمان سير العمل بكفاءة.
