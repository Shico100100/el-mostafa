# 👥 المستخدمين (Users)

هذا القسم هو الجزء المسؤول عن إدارة المستخدمين وتحديد صلاحياتهم.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي للقسم.
   - **لماذا؟** لعرض الواجهة والتعامل مع طلبات المستخدم.
   - **كيف يعمل؟** يطلب البيانات من السيرفر ويعرضها بشكل مرئي (جداول، رسوم بيانية).

### 🛠️ الوظائف المتاحة (Key Functions)
- إضافة وحذف وتعديل بيانات المستخدمين في النظام.
- تخصيص وتعديل الصلاحيات والأدوار (Roles) لكل مستخدم.
- متابعة نشاط المستخدمين لضمان الأمان والشفافية.
