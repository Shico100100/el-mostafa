# 💹 المحاسبة (Accounting)

هذا القسم هو الجزء المسؤول عن إدارة الحسابات المالية، والقيود المحاسبية، ومتابعة ميزان المراجعة في النظام.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي لقسم المحاسبة (دليل الحسابات).
   - **لماذا؟** لعرض قائمة الحسابات، ميزان المراجعة، والرسوم البيانية المالية.
   - **كيف يعمل؟** 
     - يطلب بيانات الحسابات وميزان المراجعة من السيرفر.
     - يعرض توزيع الأصول والخصوم والمصروفات بشكل مرئي.
     - يتيح إضافة حسابات جديدة وتعديل الموجود منها.

2. **`journal/` (مجلد)**
   - **ما هو؟** المجلد الخاص بقيود اليومية.
   - **لماذا؟** لتسجيل ومراجعة كافة العمليات المالية والقيود المزدوجة في النظام.

### 🛠️ الوظائف المتاحة (Key Functions)

- **إدارة دليل الحسابات**: إضافة وتصنيف الحسابات (أصول، خصوم، إيرادات، مصروفات).
- **ميزان المراجعة**: عرض ميزان المراجعة الحالي للتأكد من توازن الحسابات.
- **التقارير المالية**: رسوم بيانية توضح الوضع المالي والسيولة.
- **القيود اليومية**: إمكانية تسجيل القيود اليدوية وتتبع القيود الآلية الناتجة عن المبيعات والمشتريات.
