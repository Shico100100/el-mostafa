# ⚙️ الإعدادات (Settings)

هذا القسم هو الجزء المسؤول عن ضبط إعدادات النظام وتخصيصه.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي للقسم.
   - **لماذا؟** لعرض الواجهة والتعامل مع طلبات المستخدم.
   - **كيف يعمل؟** يطلب البيانات من السيرفر ويعرضها بشكل مرئي (جداول، رسوم بيانية).

### 🛠️ الوظائف المتاحة (Key Functions)
- تعديل بيانات المؤسسة الأساسية والشعار.
- ضبط التفضيلات العامة للنظام مثل اللغة والعملة.
- التحكم في إعدادات النظام المتقدمة لضمان عمله بكفاءة.
