# 🛒 المشتريات (Purchases)

هذا القسم هو الجزء المسؤول عن إدارة المشتريات والتعامل مع الموردين.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي للقسم.
   - **لماذا؟** لعرض الواجهة والتعامل مع طلبات المستخدم.
   - **كيف يعمل؟** يطلب البيانات من السيرفر ويعرضها بشكل مرئي (جداول، رسوم بيانية).

### 🛠️ الوظائف المتاحة (Key Functions)
- إنشاء وإدارة أوامر الشراء بدقة.
- تنظيم بيانات الموردين وتقييم أدائهم.
- تسجيل الفواتير الواردة ومطابقتها مع الاستلامات.
