# 🎨 واجهة النظام (Frontend Application)

هذا المجلد يحتوي على كل ما يراه المستخدم ويتفاعل معه في المتصفح.

### 📜 الملفات الأساسية (Core Files)

1. **`layout.tsx`**
   - **ما هو؟** الهيكل العام للموقع.
   - **لماذا؟** لتثبيت الأشياء التي تظهر في كل الصفحات (مثل القائمة الجانبية وشريط التنبيهات).
   - **كيف يعمل؟** يغلف جميع الصفحات الأخرى داخل إطار واحد موحد.

2. **`page.tsx`**
   - **ما هو؟** الصفحة الرئيسية للموقع.
   - **لماذا؟** لتعريف ما يظهر للمستخدم فور دخوله على الرابط الرئيسي.
   - **كيف يعمل؟** يوجه المستخدم عادةً إلى صفحة تسجيل الدخول أو لوحة التحكم.

3. **`globals.css`**
   - **ما هو؟** ملف التصميمات العام.
   - **لماذا؟** لتحديد الألوان والخطوط والأشكال التي تظهر في الموقع بالكامل.

---

### 📂 صفحات الأقسام (System Pages)

كل مجلد هنا يمثل "صفحة" أو "قسم" في الموقع:

- **`dashboard/`**: لوحة التحكم الرئيسية (نظرة عامة على المصنع).
- **`inventory/`**: صفحة إدارة المخازن والأصناف.
- **`sales/`**: صفحة المبيعات والعملاء.
- **`purchases/`**: صفحة المشتريات والموردين.
- **`manufacturing/`**: صفحة إدارة التصنيع والإنتاج.
- **`accounting/`**: صفحة الحسابات والقيود المالية.
- **`hr/`**: صفحة شؤون الموظفين والمرتبات.
- **`login/`**: صفحة تسجيل الدخول.
- **`settings/`**: إعدادات النظام.
- **`users/`**: إدارة المستخدمين وصلاحياتهم.
- **`reports/`**: صفحة عرض وتحميل التقارير.
- **`notifications/`**: صفحة التنبيهات.
- **`audit/`**: صفحة سجل العمليات (المراقبة).
