# 🔍 سجل العمليات (Audit Log)

هذا القسم هو المسؤول عن مراقبة وتوثيق كافة الأنشطة والتحركات التي تتم داخل النظام لضمان الشفافية والأمان.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي لسجل العمليات.
   - **لماذا؟** لعرض جدول زمني مفصل لكل عملية (إنشاء، تعديل، حذف) تمت في النظام.
   - **كيف يعمل؟** 
     - يجلب سجلات الأنشطة من قاعدة البيانات ويعرضها مرتبة زمنياً.
     - يظهر اسم المستخدم، نوع العملية، التاريخ، والتفاصيل المتعلقة بالتغيير.

### 🛠️ الوظائف المتاحة (Key Functions)

- **تتبع المستخدمين**: معرفة من قام بأي فعل وفي أي وقت تحديداً.
- **مراقبة التغييرات**: سجل مفصل للبيانات قبل وبعد التعديل (في حال دعم النظام لذلك).
- **البحث المتقدم**: إمكانية البحث في السجلات حسب اسم المستخدم أو نوع العملية (إنشاء، تحديث، حذف).
- **الشفافية والأمان**: توفير مرجع دائم للمديرين لمراجعة أي أخطاء أو تجاوزات قد تحدث.
