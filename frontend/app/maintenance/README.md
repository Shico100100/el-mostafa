# 🛠️ الصيانة (Maintenance)

هذا القسم هو الجزء المسؤول عن إدارة الصيانة وإصلاح الأعطال في المصنع.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي للقسم.
   - **لماذا؟** لعرض الواجهة والتعامل مع طلبات المستخدم.
   - **كيف يعمل؟** يطلب البيانات من السيرفر ويعرضها بشكل مرئي (جداول، رسوم بيانية).

### 🛠️ الوظائف المتاحة (Key Functions)
- متابعة مواعيد صيانة الآلات.
- تسجيل الأعطال والإصلاحات بشكل فوري.
- تنظيم جدول الصيانة الوقائية للحفاظ على كفاءة المعدات.
