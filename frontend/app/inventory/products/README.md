# 📦 صفحة المنتجات (Products Page)

هذه الصفحة هي الجزء المسؤول عن عرض وإدارة جميع المنتجات (الأصناف) في النظام.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي لصفحة المنتجات.
   - **لماذا؟** لعرض جدول المنتجات، وخانات البحث، وأزرار الإضافة والتعديل.
   - **كيف يعمل؟** 
     - عند فتح الصفحة، يقوم بطلب قائمة المنتجات من "السيرفر" (Backend).
     - يعرض البيانات في جدول منظم.
     - يحتوي على "نماذج" (Modals) تظهر عند الرغبة في إضافة أو تعديل منتج.
     - يتعامل مع عمليات مثل "تصدير البيانات إلى Excel" أو "استيرادها".

2. **`[id]/` (مجلد)**
   - **ما هو؟** مجلد للصفحات الديناميكية (مثل صفحة تفاصيل منتج معين).
   - **لماذا؟** لعرض حركات المخزن الخاصة بمنتج واحد فقط عند الضغط عليه.

### 🛠️ الوظائف المتاحة (Key Functions)

- **البحث والفلترة**: يمكنك البحث عن منتج بالاسم أو الكود، أو تصفية المنتجات حسب النوع (خامة، منتج تام) أو التصنيف.
- **إدارة النواقص**: زر خاص يعرض فقط المنتجات التي وصلت للحد الأدنى للمخزون.
- **تحديث الأسعار الجماعي**: ميزة تتيح زيادة أو نقص الأسعار بنسبة مئوية لعدة منتجات معاً.
- **الاستيراد والتصدير**: ربط النظام بملفات Excel لتسهيل إدخال البيانات الضخمة.
