# 🔔 التنبيهات (Notifications)

هذا القسم هو الجزء المسؤول عن عرض التنبيهات والإشعارات الهامة للمستخدمين.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي للقسم.
   - **لماذا؟** لعرض الواجهة والتعامل مع طلبات المستخدم.
   - **كيف يعمل؟** يطلب البيانات من السيرفر ويعرضها بشكل مرئي (جداول، رسوم بيانية).

### 🛠️ الوظائف المتاحة (Key Functions)
- عرض آخر التنبيهات والرسائل الهامة المتعلقة بالنظام.
- إرسال إشعارات بخصوص مستويات المخزون والطلبيات المتأخرة.
- إخطار الإدارة والموظفين بالتحديثات والمهام الجديدة.
