# 💰 المبيعات (Sales)

هذا القسم هو الجزء المسؤول عن إدارة المبيعات والتعامل مع العملاء.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي للقسم.
   - **لماذا؟** لعرض الواجهة والتعامل مع طلبات المستخدم.
   - **كيف يعمل؟** يطلب البيانات من السيرفر ويعرضها بشكل مرئي (جداول، رسوم بيانية).

### 🛠️ الوظائف المتاحة (Key Functions)
- تسجيل عمليات المبيعات وإصدار الفواتير للعملاء.
- إدارة قاعدة بيانات شاملة للعملاء ومتابعة تفاعلاتهم.
- مراقبة التحصيلات المالية والأرصدة المستحقة.
