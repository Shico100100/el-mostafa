# 📊 التقارير (Reports)

هذا القسم هو الجزء المسؤول عن عرض وتحميل التقارير والتحليلات البيانية.

### 📜 ملفات الكود (Code Files)

1. **`page.tsx`**
   - **ما هو؟** المكون الرئيسي للقسم.
   - **لماذا؟** لعرض الواجهة والتعامل مع طلبات المستخدم.
   - **كيف يعمل؟** يطلب البيانات من السيرفر ويعرضها بشكل مرئي (جداول، رسوم بيانية).

### 🛠️ الوظائف المتاحة (Key Functions)
- استخراج تقارير شاملة عن المبيعات والمشتريات والإنتاج.
- عرض لوحات بيانات (Dashboards) تفاعلية لتحليل الأداء.
- تصدير التقارير بصيغ مختلفة (PDF, Excel) لمشاركتها بسهولة.
