# مكونات واجهة المستخدم (UI Components)

هذا المجلد يحتوي على مكونات واجهة المستخدم العامة (الأزرار، الحقول النصية، الجداول، وغيرها).

### 📜 ملفات الكود (Code Files)
- `AttachmentSection.tsx`: مكون مخصص لعرض وإدارة المرفقات والملفات.
- `GlassPanel.tsx`: حاوية بتصميم زجاجي عصري (Glass-morphism) تستخدم لتنظيم المحتوى.
- `SearchableSelect.tsx`: قائمة اختيار متطورة تتيح للمستخدم البحث داخل الخيارات.
- `Typography.tsx`: مكونات معيارية لتنسيق النصوص والعناوين لضمان تناسق الخطوط.

### 🛠️ الوظائف المتاحة (Key Functions)
- توفير عناصر واجهة مستخدم قابلة لإعادة الاستخدام في جميع أنحاء التطبيق.
- ضمان تجربة مستخدم موحدة (Consistent UX) من خلال الالتزام بهوية بصرية واحدة.
- تسهيل بناء الصفحات المعقدة باستخدام مكونات بسيطة وجاهزة.
