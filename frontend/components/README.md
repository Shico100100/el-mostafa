# 🧩 مكونات الواجهة (Frontend Components)

هذا المجلد يحتوي على "القطع" البرمجية التي تُستخدم في بناء صفحات الموقع.

### 📜 الملفات الأساسية (Core Files)

1. **`CommandPalette.tsx`**
   - **ما هو؟** شريط البحث السريع.
   - **لماذا؟** للسماح للمستخدم بالبحث عن أي صفحة أو منتج أو عميل بسرعة بالضغط على (Ctrl+K).
   - **كيف يعمل؟** يظهر كنافذة طائرة فوق الموقع تتيح التنقل السريع.

2. **`ExcelActions.tsx`**
   - **ما هو؟** زر عمليات الإكسيل.
   - **لماذا؟** لتوفير أزرار موحدة لتصدير واستيراد البيانات في جميع الجداول.
   - **كيف يعمل؟** يتصل بالسيرفر لتحميل ملفات الإكسيل أو رفعها.

3. **`NotificationCenter.tsx`**
   - **ما هو؟** مركز التنبيهات.
   - **لماذا؟** لعرض الرسائل الهامة للمستخدم (مثل: "تم تأكيد طلب بيع" أو "عطل في ماكينة").
   - **كيف يعمل؟** يعرض قائمة منسدلة تحتوي على آخر الإشعارات الواردة.

### 📂 المجلدات الداخلية (Sub-folders)

- **`ui/`**: يحتوي على المكونات البسيطة (مثل الأزرار، الحقول، والجداول) التي تُبنى بها الواجهة.
- **`providers/`**: ملفات تقنية تربط الموقع بالخدمات الخارجية (مثل التأكد من تسجيل الدخول).
