# مزودو الخدمات (Providers)

هذا المجلد يحتوي على مزودو الخدمات على مستوى النظام (Auth, theme, etc.).

### 📜 ملفات الكود (Code Files)
- `ToastProvider.tsx`: مسؤول عن إدارة وعرض التنبيهات المنبثقة (Toast Notifications) في أي مكان داخل التطبيق.

### 🛠️ الوظائف المتاحة (Key Functions)
- إدارة الحالة العامة (Global State) والخدمات التي تحتاج للوصول إليها من أي مكون.
- توفير سياق العمل (Context) للمصادقة، اللغات، أو التفضيلات البصرية.
- ربط خدمات النظام بواجهة المستخدم بطريقة منظمة.
