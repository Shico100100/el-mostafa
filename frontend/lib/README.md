# 📚 مكتبات الأدوات (Frontend Library)

هذا المجلد يحتوي على "الأدوات" المساعدة التي يستخدمها الموقع للتواصل مع السيرفر أو ترتيب البيانات.

### 📜 الملفات الأساسية (Core Files)

1. **`api.ts`**
   - **ما هو؟** المترجم (الوسيط) بين الموقع والسيرفر.
   - **لماذا؟** لتسهيل عملية طلب البيانات وإرسالها للسيرفر (مثل تسجيل الدخول، تحميل المنتجات).
   - **كيف يعمل؟** يقوم بإرسال الأوامر للسيرفر مع "رمز الأمان" (Token) للتأكد من هوية المستخدم.

2. **`sort-utils.ts`**
   - **ما هو؟** أدوات الترتيب.
   - **لماذا؟** لترتيب القوائم والبيانات أبجدياً أو حسب التاريخ قبل عرضها للمستخدم.

3. **`usePermission.ts`**
   - **ما هو؟** حارس الصلاحيات.
   - **لماذا؟** للتأكد من أن المستخدم الحالي لديه الإذن بدخول صفحة معينة أو الضغط على زر معين (مثلاً: مدير النظام فقط هو من يرى صفحة الحسابات).
